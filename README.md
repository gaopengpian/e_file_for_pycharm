# E-file PyCharm Plugin

## 编译 (Build)

### 手动编译
双击运行 `./gradlew copyJarToRoot` (Windows下使用 `gradlew.bat copyJarToRoot`)。
编译成功后，插件文件会自动复制到项目根目录：**e_file_for_pycharm.jar**。

### 自动编译 (Watch Mode)
如果您希望在修改代码后自动编译，可以使用我为您创建的脚本：
双击运行 `watch_build.bat`，或者在终端运行：
```shell
./watch_build.bat
```
该脚本会启动 Gradle 的持续构建模式 (`-t`)，监视文件变化并在保存后自动重新打包并更新根目录下的 JAR 文件。

这是一个适配 PyCharm 2025.2.4 的 E语言 (电力系统数据标记语言) 插件。

## 功能特性

1. **模块折叠**: 支持 E 文件中模块的折叠显示。
2. **语法高亮**: 对模块的不同列和数据进行自动着色。
3. **格式化**: 右键菜单提供格式化功能，支持每个模块按列对齐。
4. **编码支持**: 强制使用 GBK 编码打开 E 文件。
5. **原生吸顶 (Sticky Lines)**: 基于深度语法树结构和 Breadcrumbs 支持向下滚动时表格头部 `<...>` 和 `@...` 行的双层无缝悬停吸附（要求 PyCharm 2024.1+）。
6. **自动版本更新提示**: 每次构建都会动态追加编译时间号作为最新插件版本，IDE 重启后自动弹窗播报。
